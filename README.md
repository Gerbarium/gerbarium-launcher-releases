## 🚀 Установка

### Windows

1. Скачай `Gerbarium-setup-x.x.x.exe` со [страницы последнего релиза](https://github.com/Gerbarium/gerbarium-launcher-releases/releases/latest).
2. Запусти установщик и следуй инструкциям на экране.
3. После установки запусти **Gerbarium** с рабочего стола или из меню «Пуск».

&gt; ⚠️ **Windows может показать предупреждение SmartScreen** («Система Windows защитила ваш компьютер»). Это нормально для новых приложений без цифровой подписи: нажми **«Подробнее» → «Выполнить в любом случае»**. Лаунчер безопасен — его исходники контролируются командой Gerbarium.


## ✨ Возможности

- 🎮 **Запуск в один клик** — сборка сервера уже настроена, ничего качать вручную не нужно
- 🔄 **Автоматические обновления** — лаунчер сам обновляется и обновляет моды при каждом запуске
- ☕ **Умная работа с Java** — лаунчер сам подберёт и установит нужную версию Java с учётом реального объёма оперативной памяти
- 📦 **Моды без боли** — все моды, конфиги и ресурсы подтягиваются автоматически и всегда актуальны
- 💬 **Discord Rich Presence** — друзья видят, что ты играешь на Gerbarium
- 📰 **Новости и чейнджлоги** — все анонсы сервера прямо в лаунчере
- 🔐 **Авторизация через аккаунт Gerbarium** — твой профиль, скин и статистика всегда с тобой
