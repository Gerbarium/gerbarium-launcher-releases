🚀 Установка
Windows
Скачай `Gerbarium-setup-x.x.x.exe` со страницы последнего релиза.
Запусти установщик и следуй инструкциям на экране.
После установки запусти Gerbarium с рабочего стола или из меню «Пуск».
> ⚠️ **Windows может показать предупреждение SmartScreen** («Система Windows защитила ваш компьютер»). Это нормально для новых приложений без цифровой подписи: нажми **«Подробнее» → «Выполнить в любом случае»**. Лаунчер безопасен — его исходники контролируются командой Gerbarium.
macOS
Скачай `.dmg` под свой процессор (Apple Silicon — `arm64`, Intel — `x64`).
Открой образ и перетащи Gerbarium в папку «Программы».
При первом запуске: Системные настройки → Конфиденциальность и безопасность → «Подтвердить вход», если macOS заблокирует приложение.
Linux
```bash
chmod +x Gerbarium-setup-*.AppImage
./Gerbarium-setup-*.AppImage
```

❓ Частые вопросы
<details>
<summary><b>Лаунчер предлагает обновление — это обязательно?</b></summary>
<br>
Да, рекомендуем обновляться всегда: обновления содержат не только новые функции, но и актуальные версии модов, без которых сервер может не пустить тебя в игру.
</details>
<details>
<summary><b>Антивирус ругается на установщик</b></summary>
<br>
Это ложное срабатывание — оно типично для приложений без платной цифровой подписи. Установщик собирается автоматически из исходного кода и не содержит ничего вредоносного. Добавь лаунчер в исключения антивируса.
</details>
<details>
<summary><b>Сколько нужно оперативной памяти?</b></summary>
<br>
Минимум 4 ГБ ОЗУ для комфортной игры, рекомендуем 8 ГБ. Лаунчер сам рассчитает оптимальный объём памяти для Java под твой компьютер.
</details>
